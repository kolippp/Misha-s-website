MISHA MYSYSHYN - WEBSITE

Extract this ZIP, then open index.html in your browser.

Includes the complete editable website, photographs, local fonts and CV.
Upload the contents of this folder to a static website host to publish it.
No installation or build step is required.

YouTube videos and the booking form require an internet connection.
The booking form sends enquiries through Formspree. Direct email links
open your email application.

For a local server, run: python3 -m http.server 4173
Then visit http://localhost:4173/
